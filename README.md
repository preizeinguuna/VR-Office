# VR Office

A simple VR office project built in Unity using the XR Interaction Toolkit and XR Interaction Simulator, featuring a custom book sorting and tracking mechanic.

## Tech Stack & Environment
* **Unity Version:** 6.0 (6000.0.80f1)
* **Platform / Build:** Windows 11 (Standalone)
* **Tools:** XR Interaction Toolkit, XR Interaction Simulator

## Features
* **Custom Code:** Uses a custom `BookCounterTracker` script and shelf sockets to track book interactions.
* **XR Interaction Simulator:** Configured for testing and simulation directly on a desktop.
* **UI Flow:** Simple dual-canvas system for navigation.
* **Ambient & Environmental Audio:** Features a synchronized ticking clock and spatial background music playback from a desktop speaker.
